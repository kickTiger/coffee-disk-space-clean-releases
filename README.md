# Coffee 磁盘空间清理 · 发布中心

## 关于应用

Coffee 磁盘空间清理是一款面向 macOS 的磁盘空间分析与清理应用，帮助查看 AI 工具缓存、模型和开发工作区构建产物的占用。应用按风险分组展示结果，由用户勾选并确认清理，默认将删除内容移入废纸篓，并保护红线目录。

本仓库用于提供官方安装包、更新清单和问题反馈，不包含应用源代码或构建系统。

## 下载与安装

当前尚未发布安装包。首个版本发布后，请从[最新版本页面](https://github.com/kickTiger/coffee-disk-space-clean-releases/releases/latest)下载适合自己 Mac 的 DMG 安装包。Apple 芯片对应 `aarch64`，Intel 芯片对应 `x86_64`；以版本页面实际提供的安装包为准。

打开 DMG，将应用拖入「应用程序」，然后启动。当前 macOS 版本沿用普通签名，尚未使用 Apple Developer ID 完成公证。首次打开时，macOS 可能要求你明确允许运行本应用；请先确认安装包来自本仓库，再按系统提示操作。

## 应用更新

应用的「关于」页面提供检查更新、启动检查和系统代理设置。更新源启用后，检查更新会使用本仓库的公开更新清单；下载安装前会验证更新包签名、版本和应用身份。安装前备份配置与台账，安装完成后由你点击重启。

发布仓库目前已建立，首个正式更新清单和安装包尚未发布，更新服务暂未启用。无法在线更新时，可从版本页面下载 DMG 手动安装。

## 维护此发布仓库

公开 Git 文件只允许下载说明、问题模板和防泄露门禁；安装包及更新清单作为 Release 资产分发。提交前检查暂存区，提交历史中也不能包含应用源码、私钥或用户数据。

在本仓库独立 checkout 中启用本地 Hooks：

```bash
chmod +x .githooks/pre-commit .githooks/pre-push
git config core.hooksPath .githooks
```

GitHub CI 会检查当前文件与历史，但不能替代提交前检查；维护者须审阅白名单与门禁变更。发现敏感内容应停止提交或发布，不要在公开 Issue 中贴出命中内容。
